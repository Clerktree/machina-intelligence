# Machina AI4I Process Quality Baseline

ExtraTrees classifier for manufacturing process failure modes using the UCI
AI4I 2020 Predictive Maintenance Dataset. The dataset is synthetic and is
useful for pipeline validation, not evidence of performance on real factory
equipment. Metrics are in `metadata.json`.
